# 登录类渠道：人工在环操作手册

> 小红书、BOSS直聘、拉勾、实习僧、猎聘这类站点，`robots.txt` 明确禁止自动化抓取
> （BOSS直聘写了 `Disallow: /*?query=*`，正好是搜索 URL；小红书是全站 `Disallow: /`），
> 而且带风控，自动抓会封号。所以工作台**不碰它们**，改成「你浏览 → 导出 → 本地导入」。
>
> **核心事实：你不需要把账号密码给我，也不需要我登录。**
> 你只需要把看到的内容整理成文本放进一个文件夹，工作台就能吃进去。

---

## 一、你最少要给我什么

一句话：**「标题 + 链接」两列就够了**，其余字段有多少给多少。

| 字段 | 是否必需 | 说明 |
|---|---|---|
| `title` | **必需** | 岗位名 / 帖子标题。中文列名写「标题」「岗位」「职位」都能识别 |
| `url` | **必需**（缺了会给占位并标注） | 详情页链接 |
| `summary` | 强烈建议 | 只要把 JD 正文或帖子内容粘一段进来，相关度打分和摘要质量会明显变好 |
| `company` / `city` / `pay` | 岗位类建议 | 会进入岗位看板的字段 |
| `tags` | 可选 | 逗号或分号分隔，会变成卡片标签 |
| `category` | 可选 | 不填会按标题关键词自动判定 |
| `source` | 可选 | 例如「BOSS直聘」，会在来源处显示，和自动采集区分开 |
| `publishedAt` | 可选 | 支持 `2026-10-01`、`2026/10/01` 等写法 |

## 二、具体操作（四种方式，选最省事的）

### 方式 A：从浏览器复制粘贴（推荐，无需装任何工具）

1. 打开 `web/data/inbox/manual.jsonl`（没有就先跑一次 `python scripts\inbox.py --template` 生成示例）
2. 每行粘贴一个 JSON 对象，照这个格式：

```jsonl
{"title": "字节跳动 多模态算法实习生（Seed）", "url": "https://jobs.bytedance.com/xxx", "company": "字节跳动", "city": "上海", "pay": "400-600 元/天", "summary": "参与多模态大模型预训练与对齐，要求熟悉 Transformer、PyTorch。", "tags": "多模态,实习", "source": "BOSS直聘"}
{"title": "面经：腾讯混元多模态一面", "url": "https://www.nowcoder.com/discuss/xxx", "summary": "手撕多头自注意力 + CLIP 对比损失推导 + 项目深挖。", "source": "牛客"}
```

3. 运行：
```powershell
python scripts\inbox.py -v          # 规范化并检查
python scripts\collect.py --only inbox   # 并入知识库
```

**省事技巧**：在浏览器里对着岗位页按 `Ctrl+L` 复制链接、`Ctrl+A` 复制正文，
两三次粘贴就能补齐一行。不用一次整理很多，一天加十个也够用。

### 方式 B：Excel / WPS 表格填，另存为 CSV（适合批量）

1. 建三列，表头写：`标题` | `链接` | `摘要`（中文表头直接识别）
2. 另存为 **CSV UTF-8**（Excel 里选「CSV UTF-8(逗号分隔)」，不要选普通的 CSV，否则中文乱码）
3. 放到 `web/data/inbox/`，然后跑上面那两条命令

可用表头（任选，中英文都行）：
`标题/岗位/职位/title`、`链接/网址/url/link`、`摘要/内容/描述/summary`、
`公司/company`、`城市/city`、`薪资/日薪/pay`、`标签/tags`、`来源/source`、`时间/日期/publishedAt`

### 方式 C：浏览器插件导出 CSV

Chrome 的「Web Scraper」「Instant Data Scraper」这类插件可以把列表页的标题+链接导成 CSV，
导出后按方式 B 丢进 `web/data/inbox/` 即可。**注意**：只导出你自己登录后能正常浏览的页面，
不要用插件做高频自动翻页。

### 方式 D：小红书帖子的整理建议

小红书是笔记形态，最有价值的往往是**评论区里的实习经验**和**内推信息**。
建议手动整理成这种粒度即可（不要整篇复制）：

```jsonl
{"title": "小红书｜2027届算法实习时间线复盘", "url": "https://www.xiaohongshu.com/explore/xxx", "summary": "9-12月是HC最充足的窗口；字节Seed要求论文+实习；面经提到多模态组会考CLIP对齐细节。", "tags": "时间线,经验", "source": "小红书"}
{"title": "小红书｜内推码：某厂多模态组", "url": "https://www.xiaohongshu.com/explore/yyy", "summary": "内推码 XXX，有效期到11月，投递时备注来源。", "tags": "内推", "source": "小红书"}
```

## 三、关于「交给我什么」

严格说，**你只需要交给我一个文件夹**：`web/data/inbox/`。
你把 `manual.jsonl` 或 `manual.csv` 放进去，剩下的解析、去重、分类、打分、入库、上界面
全部由 `scripts/inbox.py` + `scripts/collect.py` 自动完成。

不需要交的：账号、密码、Cookie、验证码、token。
**不要把这些贴进任何文件** —— 工作台完全不需要它们，而且贴进来就变成了泄露风险。

---

## 四、导入后你会看到什么

- 知识库里出现这些条目，渠道标记为 `人工导入`，来源显示你写的 `source`（如「BOSS直聘」）
- 「今日速览」和「岗位看板」会带上它们
- 岗位类条目如果填了 `company/city/pay`，会在岗位看板的投递漏斗里可以拖拽管理阶段
- 相关的面经类条目会归类到 `面试手撕题` 或对应技术分类

## 五、常见问题

**Q：导入后重复了怎么办？**
不会。导入器按 `标题+链接+公司` 生成稳定 id，跨文件去重；采集器还有四层去重兜底。

**Q：我可以直接贴一整段 JD 吗？**
可以，`summary` 会长一点，但建议只贴「职责 + 要求」两段，太长会稀释关键词匹配。

**Q：多久导入一次合适？**
随你。导入是纯本地操作，快；建议每周一次，把这一周看到的岗位和面经一起补进去。

**Q：需要我提供登录态吗？**
不需要。这是这套设计的关键取舍：**宁可少一点数据，也不碰你的账号风险**。
